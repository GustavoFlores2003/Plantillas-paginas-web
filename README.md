# Plantillas-paginas-web
Repositorio de plantillas web propias. Los archivos se encuentran consolidados en un archivo comprimido para su descarga.

Actualmente con el primer commit busco subir 5 plantillas web para criaderos de aves/mascotas y 3 plantillas para productos de mascotas, mas adelante ire agregando más plantillas de diversos tipos de negocios.
